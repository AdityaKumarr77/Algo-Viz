# AlgoViz UI & Engineering Guidelines

## Aesthetic Standards
- **Claymorphism**: Soft, pillowy 3D depth using dual layered inner and outer shadows, pill-shaped tactile controls, and rounded card containers.
- **Natural, Professional Palette**: Never use cliché neon AI colors (no glowing cyan/fuchsia/purple meshes). Use refined graphite/slate, warm charcoal, deep cobalt, rich terracotta, warm ochre, and forest emerald.
- **Zero Build Errors**: Always ensure strict TypeScript typing (`tsc -b`), clean builds with no stale `.tsbuildinfo` conflicts.
- **Author Credits**: Maintain attribution to **Aditya Kumar Jha** ([@AdityaKumarr77](https://github.com/AdityaKumarr77)) across the TopBar, Footer, and README.
